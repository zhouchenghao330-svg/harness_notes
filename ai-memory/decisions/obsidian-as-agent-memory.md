# Obsidian as agent memory

Obsidian is the long-term knowledge base for Pi. Do not build a separate memory database, vector retrieval layer, automatic extraction pipeline, or dedicated memory tool.

Pi injects `AI_MEMORY.md` at session start. When something is genuinely useful across sessions, the agent asks at a natural stopping point; after approval, it uses native Markdown read, edit, and write tools to maintain the Vault and links.

Keep the Vault simple, concise, and useful.
