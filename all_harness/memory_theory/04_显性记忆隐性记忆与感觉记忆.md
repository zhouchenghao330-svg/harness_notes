# 显性记忆 隐性记忆与感觉记忆

> 第②节第三部分。已共同阅读并确认理解，记录日期：2026-10-12。返回[[00_学习目录|学习目录]]。

**能够有意识回想的内容，与不必回想学习经历就能表现出来的能力不同。** 这一部分连接前面三类记忆，并区分人类认知分类与 Agent 的功能借用。

## 显性记忆与陈述性记忆

显性记忆，Explicit Memory，强调能够有意识地回想或识别过去获得的信息，也常称为陈述性记忆，Declarative Memory。

「记得昨天读过一篇 memory 文章」涉及情景内容；「知道情景记忆记录具体经历」涉及语义知识。它们都可以成为有意识取用的内容，不要求能完整说出所有细节。

在人类长期记忆的常见分类中，情景与语义属于显性或陈述性记忆。[Squire 与 Dede 原文](https://pmc.ncbi.nlm.nih.gov/articles/PMC4355270/)

## 隐性记忆与非陈述性记忆

隐性记忆，Implicit Memory，强调过去经验影响当前表现，而这种影响不依赖有意识回想原来的学习经历，也常称为非陈述性记忆，Nondeclarative Memory。

已经会骑车的人可以直接表现出技能，不必先回想当年哪天学的、谁教的或练习时发生了什么。程序性技能是这类记忆的重要部分，但隐性记忆不只包括程序性技能。[Squire 与 Dede 原文](https://pmc.ncbi.nlm.nih.gov/articles/PMC4355270/)

「隐性」不等于整个行动没有意识参与：可以主动决定骑车，也可以注意路况。这里关注的是技能表现是否依赖对学习经历的有意识回忆。

## 同一活动中的不同学习结果

| 保留下来的内容或能力 | 侧重点 |
| --- | --- |
| 记得父亲某天下午教自己骑车 | 情景记忆，属于显性记忆 |
| 知道自行车有哪些部件 | 语义记忆，属于显性记忆 |
| 能够维持平衡并骑行 | 程序性技能，通常归入隐性记忆 |

记得学习经历、知道相关知识和掌握实际技能是不同结果，可以同时存在，也不能简单互相替代。忘记练习细节，不等于失去骑车能力。

```text
人类长期记忆的常见简化分类
    ├─ 显性／陈述性记忆
    │      ├─ 情景记忆
    │      └─ 语义记忆
    │
    └─ 隐性／非陈述性记忆
           ├─ 程序性技能与习惯
           └─ 其他非陈述性形式
```

这不是所有人类记忆理论的唯一模型，也不把其他非陈述形式等同于程序性记忆。「人类长期记忆只有情景、语义和程序性三种」不够准确。[Squire 与 Dede 原文](https://pmc.ncbi.nlm.nih.gov/articles/PMC4355270/)

## 感觉记忆

感觉记忆，Sensory Memory，指感官刺激结束后，感官信息仍能被短暂保持，例如视觉或听觉信息的短暂痕迹。Lilian Weng 在介绍人类记忆类型时包含这一类。[原文](https://lilianweng.github.io/posts/2023-06-23-agent/#component-two-memory)

它与情景记忆关注的层次不同：感觉记忆关注刚接收到的感官信息，情景记忆关注一次具体经历。例如，看文字时短暂保持的视觉信息，与几天后记得那天在书房读过文章，不是同一种作用。接收到的信息也不会自动成为长期知识。

## 人类理论与 Agent 功能框架

在人类理论中，显性与隐性涉及有意识回忆及不同记忆系统。在 CoALA 中，情景、语义和程序性用于组织保存经历、保存知识和支持行动等功能。[CoALA 原文](https://arxiv.org/html/2309.02427v3#S4.SS1)

Agent 保存一份经历，不足以说明它具有与人类相同的主观回忆体验。读框架时，要先判断作者是在介绍人类认知，还是在划分 Agent 职责，不能把两者的分类标准直接互换。
