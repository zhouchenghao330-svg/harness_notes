## 阅读材料

### 起始文章

1. [IBM What Is AI Agent Memory](https://www.ibm.com/think/topics/ai-agent-memory)：Agent memory 的概念、用途和分类入口。
2. [Lilian Weng Component Two Memory](https://lilianweng.github.io/posts/2023-06-23-agent/#component-two-memory)：人类记忆分类的介绍，以及与 LLM Agent 的粗略对应。

### 讨论中补充的理论材料

1. [Baddeley Working Memory](https://doi.org/10.1146/annurev-psych-120710-100422)：短期保持与工作记忆中保持和操作的区分。
2. [CoALA 第 4.1 节](https://arxiv.org/html/2309.02427v3#S4.SS1)：Agent 工作记忆与长期记忆的功能组织。
3. [Squire 与 Dede Conscious and Unconscious Memory Systems](https://pmc.ncbi.nlm.nih.gov/articles/PMC4355270/)：人类显性与隐性记忆的分类。
4. [Craik 与 Lockhart Levels of Processing](https://www.sciencedirect.com/science/article/pii/S002253717280001X)：以信息加工方式研究记忆的理论视角。
5. [Tversky Encoding Processes in Recognition and Recall](https://www.sciencedirect.com/science/article/pii/0010028573900376)：预期取用任务与编码方式的关系。

### 保持与整合讨论材料

1. [CoALA 第 4.5 节](https://arxiv.org/html/2309.02427v3#S4.SS5)：保存经验与从经验中推导知识的区别。
2. [Dudai 等 The Consolidation and Transformation of Memory](https://pubmed.ncbi.nlm.nih.gov/26447570/)：人类记忆巩固中的表征变化与知识整合。
3. [Mem0 Dream 官方文档](https://docs.mem0.ai/platform/features/dream)：框架中模式综合、旧事实替代与重复记忆合并的实例。

### 检索讨论材料

1. [Tulving 与 Thomson Encoding Specificity and Retrieval Processes in Episodic Memory](https://doi.org/10.1037/h0020071)：提取线索与当初编码方式的关系。
2. [CoALA 第 4.3 与 4.4 节](https://arxiv.org/html/2309.02427v3#S4.SS3)：从长期记忆取用信息与处理当前信息的职责区别。

### 遗忘与可靠性讨论材料

1. [Richards 与 Frankland The Persistence and Transience of Memory](https://pubmed.ncbi.nlm.nih.gov/28641107/)：保持与消退共同支持决策的理论观点。
2. [Mem0 Memory Decay 官方文档](https://docs.mem0.ai/platform/features/memory-decay)：保留记录并通过检索排序减少影响的实例。
3. [W3C PROV 概览](https://www.w3.org/TR/prov-overview/)：来源与形成过程如何帮助评估可靠性。

### 时间与适用条件讨论材料

1. [Jensen 与 Snodgrass Temporal Data Management](https://www2.cs.arizona.edu/~rts/pubs/TKDEJan99.pdf)：现实有效时间与数据库记录时间的区分。
2. [Zep Facts 官方文档](https://help.getzep.com/facts)：时间边界与内容真实性的区别。

### 错误修订与记忆表示讨论材料

1. [Alchourrón 等 On the Logic of Theory Change](https://doi.org/10.2307/2274239)：撤回已有命题与纳入新信息的信念修订理论背景。
2. [Anderson 等 Remembering Can Cause Forgetting](https://doi.org/10.1037/0278-7393.20.5.1063)：人类记忆实验中的提取诱发遗忘。
3. [W3C PROV-DM](https://www.w3.org/TR/prov-dm/)：表达来源、处理过程与派生关系的模型。

### 索引与向量检索讨论材料

1. [Introduction to Information Retrieval 倒排索引](https://nlp.stanford.edu/IR-book/html/htmledition/a-first-take-at-building-an-inverted-index-1.html)：预先组织词与记录的对应关系，支持查找。
2. [Sentence-BERT](https://arxiv.org/abs/1908.10084)：用可比较的句子向量支持语义相似度检索。
3. [pgvector 索引说明](https://github.com/pgvector/pgvector#indexing)：精确近邻搜索与添加近似向量索引的区别。

### 候选记忆的选择与使用材料

1. [Generative Agents 第 4.1 节](https://arxiv.org/html/2304.03442v2)：相关性、重要性与最近访问程度的排序实例，以及在上下文窗口内选择记忆。
2. [CoALA 第 4.3 与 4.4 节](https://arxiv.org/html/2309.02427v3#S4.SS3)：从长期记忆读取到工作记忆，以及继续推理的区别。

### 记忆系统评估材料

1. [Introduction to Information Retrieval 精确率与召回率](https://nlp.stanford.edu/IR-book/html/htmledition/evaluation-of-unranked-retrieval-sets-1.html)：返回结果中的相关比例与全部相关记录中的找回比例。
2. [LongMemEval](https://arxiv.org/html/2410.10813v2)：检索与最终问答的分别评估，以及时间、更新和未知信息等能力。

### 记忆与 RAG 的关系材料

1. [Retrieval-Augmented Generation 原论文](https://arxiv.org/abs/2005.11401)：检索支持生成，以及参数化与非参数化记忆的表述。
2. [CoALA 第 4.1 节](https://arxiv.org/html/2309.02427v3#S4.SS1)：知识库作为语义记忆，以及从工作记忆的一部分组织模型输入。
