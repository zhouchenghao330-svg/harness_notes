# 候选记忆的选择与使用

> 第⑤节第三部分。已共同阅读并确认理解，记录日期：2026-10-13。返回[[00_学习目录|学习目录]]；前一部分为[[15_索引与向量检索]]。

**找到相关记录之后，还需要判断它能支持当前任务的哪一步。** 相关性、可信程度与任务价值是不同判断；进入工作记忆也不代表系统已接受它为真。

## 根据当前任务确定取用目的

教学假设：Agent 要安排某个人本周的学习计划，找到了三条记忆。

| 候选记忆 | 对当前任务的作用 |
| --- | --- |
| A：上周较忙，每天只能学 20 分钟 | 描述过去的限制，不能直接当成本周限制 |
| B：当事人本周表示，每天可以学 40 分钟 | 更直接支持本周的时间安排 |
| C：当事人表示，学习抽象概念时喜欢先看例子 | 帮助决定怎样组织学习内容 |

三条都与学习有关，但承担不同作用。检索需要明确当前任务需要什么信息，以及这些信息用于作出什么判断。

「查找关于学习的记忆」较宽泛；「查找本周可用时间和适合的讲解方式」明确了取用目的。相关性相对于当前问题而言，可用性还要看记录能够支持哪一步判断。

## 完整取用中的四个问题

1. **召回：哪些记忆值得检查？** 根据人物、关键词、时间或向量相似度取得候选。这里的召回指候选获取阶段，不是召回率指标。
2. **筛选：哪些内容符合当前条件？** 检查对象、时间、环境与适用范围。A 可作为历史背景，但不能直接充当本周限制。
3. **排序：哪些信息应优先考虑？** B 支持确定时长，C 支持组织讲解；它们承担不同作用，不必争夺统一的「最重要记忆」位置。
4. **组织：怎样让信息参与当前思考？** 保留必要条件与来源，例如把 B 表达为「当事人本周自述每天可学 40 分钟」，避免将它压缩成永久限制。

这是对职责的教学拆分，不要求固定顺序或四个独立模块。筛选可以发生在召回前，判断也可以在取用后继续进行；其中的内容理解可以由当前推理过程承担。

## 排序与可信程度的区别

| 判断 | 回答的问题 |
| --- | --- |
| 相关性 | 它与当前问题有什么关系 |
| 可信程度 | 有什么依据支持它 |
| 任务价值 | 它能帮助当前任务作出什么判断 |

错误记录也可能与问题高度相关，可靠的历史记录也可能不适用于当前任务。检索分数不能直接当成真实性分数。

Generative Agents 的论文结合相关性、重要性与最近访问程度选择记忆，再将上下文窗口容纳得下的高排名内容放入提示。这是一种设计实例，不是所有系统必须采用的公式。[原论文第 4.1 节](https://arxiv.org/html/2304.03442v2)

排序决定优先检查什么；是否采用仍需要理解内容、条件和依据。

## 进入工作记忆与接受为真的区别

CoALA 把检索描述为从长期记忆读取信息到工作记忆中，Agent 可以继续推理并更新当前工作记忆。[CoALA 第 4.3 与 4.4 节](https://arxiv.org/html/2309.02427v3#S4.SS3)

本节教学假设中的工作记忆可以同时包含：

> 当前任务：安排本周学习。  
> 当前依据：当事人本周自述每天可学 40 分钟。  
> 历史背景：上周每天只能学 20 分钟。  
> 待确认问题：本周是否还有其他限制？

这些内容都可以参与当前思考，但身份不同。历史背景、待核验主张与已经接受的依据，不会因为一起进入工作记忆就变成同一种事实。

因此，候选取得之后还需要判断与组织，明确每条记忆在当前任务中的作用。工作记忆基础见[[02_短期记忆工作记忆与长期记忆]]；来源与推断边界见[[11_来源证据与推断]]。

## 理解确认与继续位置

理解检查：「这条记忆已被检索出来并进入工作记忆，所以 Agent 已经把它接受为真。」这句话是否成立？

用户回应「我懂了，写入，然后进入下一部分」，确认理解并授权记录，没有另行给出逐项答案。该例子的分析是：不成立；取得某个主张与接受它为真是不同状态。
