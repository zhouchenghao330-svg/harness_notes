# 短期记忆 工作记忆与长期记忆

> 第②节第一部分。已共同阅读并确认理解，记录日期：2026-10-12。其余预定分类内容已记录在后续笔记，见[[00_学习目录|学习目录]]。

**短期记忆侧重临时保持，工作记忆侧重当前任务中的保持与处理，长期记忆侧重较长时间范围内的保持与取用。** 三者不能仅按名称理解为互不来往、完全互斥的区域。

## 短期记忆强调暂时保持

短期记忆，Short-term Memory，简称 STM，让信息在短时间内保持可用。

例如，收到验证码 583921 后，暂时记住它，切换页面并输入。输入完成后，通常不再需要继续保留这串数字。

```text
接收到数字 → 暂时保持 → 稍后使用
```

先理解「暂时保持」，不把具体秒数或容量当作所有场景的统一边界。

## 工作记忆强调当前保持与操作

工作记忆，Working Memory，简称 WM，在完成当前认知任务时保持并操作所需的信息。

暂时记住验证码体现临时保持；如果需要倒序输入，还要一边保持原数字，一边调整顺序，得到 129385。

```text
保持信息 + 操作信息 → 完成当前任务
```

Baddeley 在理论综述中采用了这样的区分：短期记忆侧重临时存储，工作记忆涉及存储与操作。不同理论对两者的定义和关系存在差异，因此不能始终把它们当作完全相同的概念。[Baddeley 原文](https://doi.org/10.1146/annurev-psych-120710-100422)

例如，比较「短期记忆强调保持」与「工作记忆还涉及操作」两句话时，相关信息正参与当前的理解活动。

**工作记忆强调当前可用并参与处理，不只是最近出现过。** 以前学过的知识被取出参与当前推理，也可以成为当前工作记忆中的内容。

## 长期记忆强调较长期保持与取用

长期记忆，Long-term Memory，简称 LTM，使信息可以在较长时间后被再次取用，超出眼前的临时保持。

例如，今天理解短期记忆和工作记忆的区别，几天以后仍能利用它理解新文章。

```text
今天获得知识 → 较长期保持 → 之后重新取用
```

长期不等于永久存在、随时可以取出或内容一定正确。**是否保持、能否取出、内容是否正确，是不同问题。** Lilian Weng 借用了短期和长期的区分，帮助介绍 Agent 在不同时间范围内利用信息的方式。[原文](https://lilianweng.github.io/posts/2023-06-23-agent/#component-two-memory)

## 工作记忆与长期记忆的协作

长期记忆提供过去积累的信息，工作记忆支持当前正在进行的处理。

```text
长期保留的知识
      ↓ 取用
当前工作记忆 ← 当前读到的新信息
      ↓
比较 理解 作出判断
      ↓
部分结果被长期保留
```

这是一种功能关系，不要求每次处理都必须读取长期记忆或写入新记忆。当前信息足够时，可以直接完成任务。

CoALA 以类似方式组织 Agent 的记忆：工作记忆维护当前决策所需的活跃信息，长期记忆中的内容可以被检索进来参与当前推理。[CoALA 第 4.1 节](https://arxiv.org/html/2309.02427v3#S4.SS1)

取用一条长期记忆，不意味着原来的长期记录被搬走或变成了短期记录。长期保持的内容在当前处理中被重新使用；这里分别描述保持方式与当前使用状态。

## 对用户理解的澄清

用户提出的理解是：

> 工作记忆相当于当下为了解决问题需要的信息量；为了更好地解决当下问题，需要向长期记忆获取信息来辅助。

这抓住了两者的协作关系，但「需要的信息量」应改为**当前正在保持和使用的信息**。

| 表达 | 区别 |
| --- | --- |
| 信息量 | 描述信息有多少 |
| 当前工作记忆中的信息 | 描述哪些信息当前可用并参与处理 |

工作记忆可以包含当前收到的问题和条件、从长期记忆中取出的相关知识，以及推理产生的中间结果。理论上需要但尚未获得的信息，不能仅因为需要它，就认为它已经在工作记忆中。

教学例子延续第一节的假设：

```text
当前输入：帮我安排今天的学习
长期记忆提供：用户每天只有 20 分钟
处理中形成：今天适合只安排一个概念
```

这些内容共同参与当前判断。这里的 20 分钟仍是示例条件，不是用户实际偏好的记录。

**已确认的表述：工作记忆支持当前处理，长期记忆保存之后可以取用的信息。需要时，长期记忆中的相关内容被取出，参与当前处理。**

边界检查：一条知识虽然保存在长期记忆里，但当前未被取用，它就尚未成为当前工作记忆中的内容。

用户在澄清后再次确认「我懂了」。本节的第一部分已共同阅读并确认理解。
