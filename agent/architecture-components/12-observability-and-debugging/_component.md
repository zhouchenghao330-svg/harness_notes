# 12 Observability And Debugging

## 这个组件研究什么

当 agent 行为不对时，系统给了你哪些抓手去理解它。

## 应该回答的问题

- 日志在哪
- event stream 怎么投影
- tool trace / model trace 怎么看
- replay、diagnostics、doctor、status 工具有哪些
- 调试粒度是 turn 级、tool 级，还是 event 级

## 典型关注点

- logs
- diagnostics
- event projector
- doctor / status / debug UI
