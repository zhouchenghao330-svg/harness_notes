# 00 System Overview

## 这个组件研究什么

先从系统级别回答：

- 这个 agent 的目标形态是什么

- 哪些是核心路径，哪些是增强层

## 应该回答的问题

- 这是单 agent、agent + tool、还是 agent + runtime + memory + gateway 的系统
- 它的“主执行路径”长什么样
- 哪些能力是默认内置，哪些是外挂扩展
- 哪些组件最重，哪些组件只是壳
