# 06 Subagents And Multi-Agent Coordination

## 这个组件研究什么

一个 agent 何时会派生子 agent，以及父子 agent 之间如何隔离和协作。

## 应该回答的问题

- 子 agent 的创建入口是什么
- 上下文怎么隔离
- 工具权限如何收缩
- 子 agent 结果如何汇总回主 agent
- 有没有并行、多专家、delegate 机制

## 典型关注点

- delegate_task
- subagent session
- parent/child result flow
- parallel orchestration
