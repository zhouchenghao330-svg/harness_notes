# 03 Memory And Recall

## 这个组件研究什么

agent 如何跨 turn、跨 session 地“记住”和“找回”信息。

## 应该回答的问题

- durable memory 怎么存
- session recall 怎么做
- memory 抽取是谁决定的
- recall 是原文检索、embedding、知识图谱，还是用户画像 synthesis
- 记忆是本地单机，还是依赖外部服务

## 典型关注点

- built-in memory
- session recall
- background review / curation
- external memory provider
